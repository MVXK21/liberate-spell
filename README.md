# Liberate Spell

An OpenMW mod that adds **Liberate**, an Alteration spell that frees slaves without needing the key to their bracers.

Cast Liberate on a slave and the enchantment on their bracers wavers. Talk to them within about a minute and the **go free** topic offers to break the enchantment. Freeing them works exactly like using the key: the bracers drop, the slave's disposition rises, and the Twin Lamps freed-slave count goes up.

## Getting the spell

Liberate is sold by **Imperial Cult members who sell spells**. In vanilla Morrowind those are Lalatia Varian and Somutis Vunnis at Wolverine Hall in Sadrith Mora, plus Ygfa, Aunius Autrus, Scelian Plebo, Synnolian Tunifus and Chaplain Ogrul. Tamriel Rebuilt's Imperial Cult spell sellers stock it too.

| | |
|---|---|
| School | Alteration |
| Range | Target or touch |
| Cost | 15 magicka |
| Duration | 5 seconds |

## Requirements

- **OpenMW 0.51 or newer.** The spell is created with OpenMW's load-time Lua API, so this mod does **not** work in the original Morrowind engine or with MWSE.
- Morrowind.esm

## Installation

### Mod Organizer 2

Install the archive as a mod, then enable `LiberateSpell.esp` and `LiberateSpell.omwscripts` in the plugin list. Place them after any other slave dialogue mods.

### Manual (openmw.cfg)

1. Extract the archive to a folder, for example `C:\Games\OpenMW Mods\Liberate Spell`.
2. Add these lines to your `openmw.cfg`:

   ```
   data="C:\Games\OpenMW Mods\Liberate Spell"
   content=LiberateSpell.esp
   content=LiberateSpell.omwscripts
   ```

You can also add the folder and tick both files in the OpenMW Launcher.

## Compatibility

- **Works with any slave that uses the standard slave script**, including vanilla, Tamriel Rebuilt, and most mods that add slaves.
- **Free the Slaves:** compatible. Load Liberate Spell after it so the spell's dialogue choice comes first.
- **Quest slaves are skipped on purpose.** Eleedal-Lei, Dahleena, Hides-His-Foot and Llaals Ores have quest steps tied to being freed, so the spell tells you they must be freed another way.
- Some Tamriel Rebuilt slaves use quest-specific scripts without the standard slave status. The spell says there are "no bonds" on those.
- Safe to add to an existing save. Removing it mid-game is safe too, though any merchant who already stocked the spell keeps it.

## How it works

- `scripts/liberatespell/load.lua` creates the Liberate magic effect (based on Open) and the spell.
- `scripts/liberatespell/npc.lua` notices when the effect hits an NPC, and adds the spell to Imperial Cult spell merchants.
- `scripts/liberatespell/global.lua` checks that the target is an unfreed slave, then gives the player a hidden token item for 60 seconds of game time.
- `LiberateSpell.esp` adds greeting and **go free** dialogue that appears while you hold the token. Choosing to free the slave sets their `slaveStatus` to 3, the same as the vanilla key dialogue.

While the spell is active, the token shows in your inventory as "Liberate (spell effect)". The dialogue option isn't tied to the slave you cast on: if you talk to a different slave within the minute, that one gets the option instead.

## Building from source

The plugin is generated by a script rather than made in the Construction Set:

```
python tools/build_esp.py
python tools/package.py
```

`build_esp.py` writes `mod/LiberateSpell.esp`. `package.py` builds the release zip in `dist/`.
